# Consultas SQL – IndieDev Hub

Esta pasta contém as dez consultas SQL desenvolvidas para atender aos requisitos da Parte 3 do Projeto Final da disciplina CIN 8003 – Bancos de Dados e Aplicações.

Cada consulta está armazenada em um arquivo individual e apresenta, em seu início, um comentário explicando seu objetivo.

## Consultas disponíveis

| Arquivo | Objetivo |
|---|---|
| consulta1.sql | Contabilizar tarefas por equipe utilizando COUNT, INNER JOIN e GROUP BY. |
| consulta2.sql | Somar os testes obrigatórios por versão utilizando SUM e LEFT JOIN. |
| consulta3.sql | Calcular a média de tarefas por projeto utilizando AVG e subconsulta. |
| consulta4.sql | Identificar as datas mínima e máxima das versões por projeto utilizando MIN e MAX. |
| consulta5.sql | Identificar equipes com pelo menos dois projetos utilizando COUNT e HAVING. |
| consulta6.sql | Identificar versões com testes obrigatórios reprovados utilizando SUM, CASE e HAVING. |
| consulta7.sql | Utilizar subconsultas com IN e expressão escalar para analisar os bugs dos projetos. |
| consulta8.sql | Identificar equipes que possuem tarefas pendentes utilizando EXISTS. |
| consulta9.sql | Apresentar um resumo de tarefas e bugs por projeto utilizando CTE, LEFT JOIN e COALESCE. |
| consulta10.sql | Demonstrar operações de transação utilizando COMMIT, ROLLBACK e SAVEPOINT. |

## Recursos SQL contemplados

As consultas foram elaboradas para demonstrar os seguintes recursos:

- Funções agregadas: COUNT, SUM, AVG, MIN e MAX.
- Junções: INNER JOIN e LEFT JOIN.
- Agrupamento e filtragem: GROUP BY e HAVING.
- Ordenação: ORDER BY ASC e DESC.
- Subconsultas: escalar, IN e EXISTS.
- Expressões de tabela comuns: CTE.
- Tratamento de valores nulos: COALESCE.
- Transações: COMMIT, ROLLBACK e SAVEPOINT.

## Execução

As consultas foram desenvolvidas para o banco de dados SQLite e testadas utilizando o DB Browser for SQLite.
