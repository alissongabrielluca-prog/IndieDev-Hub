# Documentação – IndieDev Hub

Esta pasta reúne os documentos que descrevem os requisitos e a estrutura lógica do banco de dados do projeto IndieDev Hub.

## Arquivos disponíveis

### 1. Modelo de Requisitos
**Arquivo:** `IndieDev_Hub_Modelo_de_Requisitos.docx`

Documento que apresenta a descrição do sistema, seus objetivos, stakeholders, requisitos funcionais e não funcionais, regras de negócio, requisitos de informação e limites do escopo.

### 2. Modelo Lógico – Esquema Relacional
**Arquivo:** `IndieDev_Hub_Modelo_Logico.pdf`

Documento que apresenta as doze relações do banco de dados, seus atributos, chaves primárias, chaves estrangeiras, restrições de integridade e relacionamentos.

## Projeto

**Nome:** IndieDev Hub  
**Disciplina:** CIN 8003 – Bancos de Dados e Aplicações  
**Instituição:** Universidade Federal de Santa Catarina (UFSC)

Os documentos servem como referência para a construção e validação do banco de dados implementado em SQLite.
